## 2. 不变量（别退回去）

这些是迁移过程中反复踩到、最后固化成测试的硬约束：

1. **节点只有一种**：`Node2`。不存在"声明层 → IR"的第二跳，
   `children` 就是 `Vec<Fc>`，`Fc = (ctx) => void`。
2. **`skip_draw` 跳过整棵子树**（`render_node2` 在递归前 `continue`）。
   带子节点的容器不要用它来表达"我不画自己"——不给 `draw` 就行。
3. **`align_item: Stretch` 必须配 `align_fix: true`**，否则容器交叉轴取
   "非对齐子节点最大尺寸"；当所有子节点都是 stretch 时取到 0，整列宽度塌成 0。
4. **显式 `width`/`height` 压过 `Stretch`**：想靠父级拉伸就别给交叉轴声明尺寸。
   （分割条踩过：`width: if X {6} else {0.0}` 让竖向分割条宽度恒为 0。）
5. **`node2!` 不写 `layout` = 绝对定位**，子节点全钉在 `(0,0)`、容器量不到尺寸。
   凡是"包一层装子节点"的 wrapper 都要写 `layout: flex! { .. }`。
6. **文本一律是文本子节点**（`text_label!` / `wrapped_text_node!`），
   不用 `Scene::draw_text` 手绘。例外只有图表内部的坐标轴刻度与十字光标读数
   ——它们跟着数据每帧重算，属于绘图区的一部分。
7. **`align_item: Center` + 不给 `height` + `align_fix: true` → 高 0**
   （交叉轴尺寸成环回到父级）。按内容定高的容器不要给 `align_fix`。
